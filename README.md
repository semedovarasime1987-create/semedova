# Təhsil haqqında Qanun üzrə test

Azərbaycan dilində 80 suallıq test bankından hər cəhd üçün 15 sual seçən statik test tətbiqi.

## Funksiyalar
- 80 suallıq bank
- Hər cəhddə 15 sual
- Hər suala 90 saniyə
- 4 cavab variantı, 1 düzgün cavab
- Düzgün cavab mövqeləri qarışdırılır
- "Yenidən başla" yeni sual dəsti yaradır
- Nəticə və cavab icmalı

## İşə salınma
`index.html` faylını brauzerdə açmaq kifayətdir. GitHub Pages ilə də yayımlana bilər.

Məzmun istifadəçinin təqdim etdiyi “Təhsil haqqında” Qanunun I fəsil, 1–7-ci maddələri üzrə hazırlanmış material əsasında qurulub.
